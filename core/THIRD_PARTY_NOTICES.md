# Astronomy formulas

Parts of `Astronomy.kt` adapt the new-moon and low-precision solar-coordinate
formulas implemented by [Sonia Keys' meeus project](https://github.com/soniakeys/meeus),
under the MIT license. The calendar-month construction, Vietnamese labels and
application almanac rules were written for this application. This module contains
no code from the noncommercial-licensed Ho Ngoc Duc calendar implementation.
